一些图标库解决方案

  • Bootstrap Icon
  • Fontawesome

二次开发组件

  • 第一步：支持组件的原始属性
    • inheritAttrs:false 不继承属性
    • 使用$props访问所有属性
    • 要注意不继承以后一些默认属性失效的问题$attrs
  • 第二步：扩充组件属性
    • 我们添加的type/color属性
    • 过滤传递的属性 lodash omit
